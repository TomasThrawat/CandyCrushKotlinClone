# Sweet Match

A small Android match-3 puzzle game written entirely in Kotlin.

## Features

- 8x8 match-3 board
- Swipe adjacent pieces to swap them
- Matches of 3 or more are cleared
- Gravity and random refill
- Cascading combos
- Score and 30-move limit
- Original candy shapes drawn with Android Canvas
- No third-party game engine or copyrighted game assets

## Build

Open the project in Android Studio with JDK 17, let Gradle sync, then run the app configuration on an Android device or emulator.

The project targets Android API 35 and supports Android API 23+.
